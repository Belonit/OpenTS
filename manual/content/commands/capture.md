A relative path is taken from the game's own folder. [Map capture description](/formats/capture-ini/) describes the file, what a capture draws, and how the game exits.

Giving it with [`-CAPTUREMAP=`](/using/command-line/#capture-map) or [`-CAPTUREOUT=`](/using/command-line/#capture-output) stops the run before the map is loaded.
