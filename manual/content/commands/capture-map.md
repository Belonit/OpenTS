command_id: launch:capture-map

Name the picture with [`-CAPTUREOUT=`](/using/command-line/#capture-output); without it, the game exits at once. [Map capture description](/formats/capture-ini/#what-a-capture-draws) says what a capture draws and how the game exits, and [`-CAPTURE=`](/using/command-line/#capture) takes a file with more settings.
